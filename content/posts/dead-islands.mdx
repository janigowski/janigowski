Files that only import each other. Dead code checks might miss them. A file graph with an LLM helps find them.

Tools like Knip treat tests and stories as entry points, so they can miss them.

I used [Graphify](https://graphify.com). It builds a graph of files and imports, and you can ask an LLM questions about it. The idea is general, not tied to one tool.

I asked for files that nothing imports. It found them. But it also found something I didn't ask for: dead islands.

## A dead island

A dead island is a group of files that only import each other. Nothing outside the group imports them.

The smallest one is two files: a component and its test. The test imports the component, so the component looks used.

`useElementSize.ts` is 52 lines. The only file that imports it is `useElementSize.test.ts`, 252 lines.

## One example

6 files in 3 folders. A container, the button it renders, two test files and two test mocks. 467 lines, and only 168 of them are product code. Nothing in the app had used it for about a year.

`InvoiceMenu.test.tsx` and `InvoiceMenu.export.test.tsx` import `InvoiceMenu.tsx`, which renders `MenuItem.tsx`. The tests also import two mocks: `csvFile.mock.ts` and `zipFile.mock.ts`.

The island imports 28 files from the app. The app imports none back.

## Why it matters

Software hygiene. Dead files are not free.

Every refactor, codemod, search and AI agent run reads them, and often changes them. You keep maintaining code nobody uses. Less code to maintain, for people and for agents.

## Try it on your codebase

### 1. Build the graph

Build a graph of your codebase: files and their imports. I used [Graphify](https://graphify.com).

```bash
uv tool install graphifyy
graphify extract . --code-only
```

The package is `graphifyy`. The command is `graphify`. Run it from the repo. `--code-only` reads the code on your machine and needs no API key.

Similar tools should work the same, if they build a file/import graph you can query with an LLM.

### 2. Ask

Then ask the LLM:

<PromptLines

	]}
/>

If you want it in one go, paste this into Cursor, Claude Code, or another coding agent.
