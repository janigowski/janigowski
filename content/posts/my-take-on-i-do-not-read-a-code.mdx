I doubled down on the phrases I hear often recently.

<blockquote cite="influencers">
I do not read a code anymore
</blockquote>


<blockquote cite="influencers">
Stop reading code
</blockquote>




--------

I think saying it loud is harmful. Especially when your audience is huge.

Code, as an output is only part of the entire process of provlem solving process, which essentialy each successful product does.
- Google - how to find X in the internet?
- Browser - how to navigate through it?
- Miro - how to share ideas visually?

Code solves some issue. Nevermind its quality. What's important - you have to understand the problem first to somehow type those characters out of around 50 from your keyboard, in correct order to make the machine solve it.

Coder gains experience by solving more, diverse problems and understanding them better. Not by typing the same code over and over again.
Then, <strong>Learning Loop</strong> can be defined as:
- listen
- understand
- design
- code
